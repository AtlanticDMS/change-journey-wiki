## Definition
A technology that uses software "bots" to automate repetitive, rule-based tasks previously performed by humans — such as data entry, invoice processing, report generation, and system-to-system data transfer. Often combined with AI to handle less structured inputs.

## Why it matters
RPA delivers immediate, measurable efficiency gains with relatively low implementation complexity. It is often the most accessible entry point to automation for SMBs, requiring no changes to underlying systems.

## How it works
RPA bots mimic human actions on digital interfaces — clicking, copying, pasting, form filling — across existing software systems. Unlike system integrations, RPA sits on top of existing tools without requiring API access or system changes.

Key providers: UiPath, Automation Anywhere, Blue Prism.

## Department-by-department opportunities (from Ch. 8)
- **Finance** — invoice processing, reconciliation, expense reporting
- **HR** — onboarding documentation, payroll data entry, compliance reporting
- **Sales** — CRM data updates, lead routing, quote generation
- **Operations** — inventory updates, order processing, supplier communications
- **Customer service** — ticket routing, response templating, follow-up scheduling
